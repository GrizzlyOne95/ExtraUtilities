# Local reactive material presentation

These optional APIs preserve the source material's techniques, textures and render states. They make no gameplay or network changes. Shader uniforms must exist on the selected fragment program; unsupported uniforms return zero rather than inventing a shader replacement.

- `CloneSurfaceMaterial(source, name)` creates a runtime-owned clone in General. Names must start `exu_surface_`, maximum 160 bytes. The native owner holds references through the released Ogre ABI and caps the combined pool at 1,024 materials. Existing foreign names are rejected.
- `SetSurfaceMaterial(target, zeroBasedSubEntity, name)` assigns an owned clone; resolve the entity again each call. World handles and `{kind="cockpit", handle=h}` targets are supported.
- `ReleaseSurfaceMaterial(name)` removes the manager entry and native owner reference. Restore assignments first, and only if the current assignment is still yours. Ogre renderable references keep a material alive until detached. Lua-state shutdown clears the remaining native pool; scene objects must be rebuilt/reset with the mission.
- `SetMaterialShaderVector(material, parameter, x,y,z,w, technique=-1, pass=-1, group="General")` writes a finite float4 to matching fragment programs and returns the number of changed passes. Negative technique/pass selects all supported passes; owned surface materials visit all their techniques. Absent or differently typed uniforms are skipped. This uses ordinary material constants, avoiding missing Renderable custom-parameter values leaking between draws.
- `SetSurfaceTexture(ownedName, textureAliasOrUnitName, texture)` matches names without case sensitivity across all techniques, including Glow. Returns changed unit count. Use a black emissive texture to suppress bloom as well as lit emission.
- `EntityLocalPoint(target, simulationWorldPoint)` returns a vector in the actual entity parent node's local coordinates, accounting for derived translation, rotation, nonuniform scale and the simulation/render origin. Returns nil if unavailable. This is a rigid projection; it does not track a skinning bone or rotating submesh automatically.
- `GetWeaponMuzzlePosition(handle, slot)` returns the current corrected native firing mount in simulation coordinates, or nil. Slot is 0–4. Requires OpenShim's qualified presentation adapter and a bound weapon. It currently fails closed outside the exact supported GOG single-player adapter, with unavailable/disabled native presentation, or before a first accepted shot binds the weapon. Never substitute an estimated hull anchor.
- `IsGunTowerPowered(handle)` returns true/false for class `turret` using the engine's actual current power source. Returns nil for other classes or an unsupported power-layout anchor. This does not apply to mobile `turrettank` objects.
- `SetReactiveChunksEnabled(boolean)` opts the optional OpenShim debris bridge into source-preserving shared material variants (at most 128 source variants within the combined pool). Off by default and reset at Lua-state shutdown. Only debris creation/batch creation calls the bridge; it never invokes Lua in a render hook. Flesh/blood materials retain their own presentation. Existing cached debris resources need a scene rebuild to change their finish.

The owned pool and parameter cache serialize Lua updates, native debris creation
and lifecycle teardown. Runtime reference counters use the released Ogre control
block layout; public SDK SharedPtr instances must not own returned references.

Campaign-specific easing, range limits, event queues, palette and cleanup live in CR's `CRSurfaceEffects.lua`. Reuse existing BulletInit/BulletHit callbacks by chaining them and doing only bounded data copies there. Do renderer work from Update. New interfaces add no paths, dependencies or startup hooks; missing modules, unsupported builds, shader families or render systems retain their existing presentation. Windows/GOG is the first live target; Steam, Wine/Proton and other renderer paths need separate live qualification.
