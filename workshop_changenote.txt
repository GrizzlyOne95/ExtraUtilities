Extra Utilities 1.3.0

New for mission scripts:
- Static geometry: build mission-scoped static geometry for large numbers of props.
- Particles: attach particle systems to the camera, objects or skeleton bones, and tune emitters and affectors live.
- Weather: light and heavy rain, dust and mist profiles with a reusable controller (exu_weather).
- Optional render-effect requests to OpenShim (SSAO, depth haze, soft particles) when OpenShim provides them.

Stability and safety:
- Dead or recycled unit handles are rejected instead of reading freed objects.
- Every fixed-address patch checks the game's original bytes first, and EXU refuses to patch or call into an unrecognised game build.
- Mission state (patches, overlays, particles, fog, culling, command replacements) is reset when a mission ends, so nothing leaks into the next mission.
- Several crash fixes in AI task inspection, ordnance, storage and overlays.

Behaviour changes:
- exu.SaveGame keeps mission saves intact, writes binary saves when the game runs with -binarysave, and only writes files inside the game's Save folder.
- Turbo, infinite ammo/scrap and ordnance velocity work in multiplayer. Each machine applies them locally, so every player's script must make the same call.
- SetOverlayColor, SetOverlayMetricsMode and SetOverlayMaterial now work correctly on text areas and panels.
- GetGameKey reports keys as held only while they are held and the game window is focused.
- DrawLine, DrawBox and ClearVisuals are placeholders that draw nothing yet.

Requires the Microsoft Visual C++ 2015-2022 Redistributable (x86).
