[h1]Extra Utilities[/h1]

Extra Utilities (EXU) is a native Lua script extender and utility library for Battlezone 98 Redux. It exposes engine, renderer, UI, object, multiplayer, particle, animation, storage, continuity, and gameplay controls that stock mission Lua does not provide.

[h2]Highlights[/h2]
[list]
    [*] Camera, FOV, projection, clip-distance, viewport, and display control
    [*] Fog, gravity, sun/ambient lighting, sky, terrain, and material controls
    [*] Ogre overlays, text, HUD layout, radar, reticle, and satellite helpers
    [*] Particle-system creation, attachment, and live emitter control
    [*] Game-object, AI, ordnance, physics, weapon-selection, and construction helpers
    [*] Multiplayer helpers and synchronized/asynchronous object creation
    [*] Persistent storage and mission-to-mission continuity APIs
    [*] Optional OpenShim bridges for shared engine-owned behavior
[/list]

[h2]Using EXU[/h2]

Install EXU through this Workshop item or use the DLL from the latest GitHub release, then load it from Lua:

[code]local exu = require("exu")[/code]

Mod authors should prefer the shared EXU installation rather than bundling private copies of exu.dll. A shared copy receives fixes and reduces conflicts between mods expecting different EXU versions.

Editor annotations and the Lua API surface are maintained in Definitions/ExtraUtils.lua in the GitHub repository. Focused examples are also included in the repo.

[h2]Compatibility[/h2]

EXU targets Battlezone 98 Redux 2.2.301 as a 32-bit Windows DLL. The same exu.dll is used by Steam Proton/Wine installations; there is no native Linux .so build.
